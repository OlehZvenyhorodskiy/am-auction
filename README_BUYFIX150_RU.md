# AuctionHousAqua20-buyfix150

Исправление покупки лотов, которые выставляют fake-players/боты через `/ah sell <цена>` на сервере-продавце.

Что изменено:
- покупка перед выполнением точечно перечитывает выбранный лот из MySQL по id, даже когда Redis включен;
- локальные stale/ghost записи на сервере-продавце больше не блокируют покупку;
- возврат к совместимому с AuctionHousAqua9 поведению: купленный предмет кладется в AuctionBox покупателя, а не напрямую в инвентарь;
- не отменяет покупку, если Vault/economy не смог зачислить деньги fake-player продавцу; для ботов это не должно блокировать выдачу предмета игроку;
- добавлены логи `[BuyFix150]`.

Ставить вместо AuctionHousAqua19-runtimefix148. На связанных серверах можно оставить старую версию, но лучше обновить все узлы, чтобы логика покупки была одинаковой.
