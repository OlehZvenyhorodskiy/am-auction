# AuctionHousAqua v1.21.8-1.4.7-perffix155

Готовая сборка и исходный код плагина аукциона для Paper / Purpur 1.21.x (Java 21).

## Содержимое архива

- `AuctionHousAqua-1.21.8-1.4.7-perffix155.jar` — готовый скомпилированный плагин для папки `plugins/`.
- `src/` — полный исходный код проекта.
- `pom.xml` — файл сборки Maven со стандартными репозиториями (PaperMC, JitPack).
- `README.md` и сопутствующая документация.

## Ключевые исправления и доработки

1. **Устранение спама и фризов (110k строк логов в сутки)**:
   - Синхронная блокирующая перезагрузка всей базы данных заменена на асинхронное получение слепка (`DatabaseSnapshot`) на отдельном короткоживущем соединении.
   - Применение данных происходит в основном потоке без выполнения тяжелых SQL-запросов, предотвращая микрофризы сервера.
   - Устранена проблема N+1 запросов при чтении истории ставок: теперь таблица `bids` вычитывается одним запросом.

2. **Синхронизация между серверами**:
   - Реализована мгновенная синхронизация через Redis (pub/sub).
   - При активном Redis отключен периодический опрос базы данных (`syncIntervalSeconds: 0`), что снижает нагрузку на MySQL.

3. **Универсальная база данных (MySQL + SQLite)**:
   - В `config.yml` поддержан параметр `auction.database.type: mysql` (по умолчанию) и `sqlite`.
   - Для локального тестирования или одиночных серверов плагин может работать полностью автономно через SQLite без внешнего MySQL-сервера.

4. **Защита от утечек соединений и зависаний Watchdog**:
   - Добавлено автоматическое закрытие `PreparedStatement` при завершении `ResultSet`.
   - Внедрен тайм-аут при отключении плагина: если сокет MySQL завис, соединение закрывается принудительно, предотвращая зависание сервера при перезагрузке или `/stop`.

5. **Стандартизация сборки**:
   - Удалены локальные жесткие пути к библиотекам.
   - Проект собирается стандартной командой `mvn clean package`.

## Установка

1. Скопируйте файл `AuctionHousAqua-1.21.8-1.4.7-perffix155.jar` в папку `plugins/` вашего сервера.
2. Убедитесь, что на сервере установлены `Vault` и плагин экономики (например, `EssentialsX`).
3. Запустите сервер для генерации папки `plugins/AuctionHousAqua/`.
4. Настройте подключение к MySQL или SQLite в `plugins/AuctionHousAqua/config.yml`.
5. Выполните команду `/ah reload` или перезапустите сервер.
